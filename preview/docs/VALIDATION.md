## 发现并修复

- 完整流程缩放后文字过小：总览改为大标题和处理器数量，放大显示处理器摘要；手机初始聚焦所选节点，保留完整图和缩放控制。
- 资源表单复用插件配置提交辅助函数时带上旧 services/connectors/dependencies 字段：新资源接口明确排除这些字段，表单只提交 revision、release、target、values、secrets。
- 研究页下拉框增加明确的输入辅助标签；测试点击 Vuetify 外层 combobox，避免误把被选中文本覆盖的内部输入当作点击目标。
- 发现 Bun.write 的 mode 参数未按预期设置权限：预览配置与状态改用 Node 文件接口创建 0600 文件，状态以独占创建的临时文件原子替换；重新打开时也修正旧状态文件权限，并用 stat 验证。
