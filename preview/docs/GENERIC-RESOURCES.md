# 资源理解修正

原设计把资源限定为 Bot 认可的能力种类，抽象位置错误。本次移除运行时和前端的资源类别，提供者声明任意操作及其数据结构，Bot 只实现注册、配置展示、校验、调用和引用协议。

演示路径：打开资源页，找到“业务查询 API”或“文档处理实例”，点“查看与测试”。API 例子可以提交 R-123；文本整理可以提交带空白和空行的文本；统计操作展示同一资源暴露多个操作。输入非法参数会被 JSON Schema 拒绝。所有例子调用同一 HTTP 入口，没有 LLM 调用。

现有 GSVI/ComfyUI/实验室样例也使用同一协议，只是普通插件。预设的资源选择已改为具体操作引用，群私聊策略和编排逻辑保持。

真实 MCP 服务/导入与资源转指令属于后续方向，本次只提供可被它们消费的操作契约、引用以及可运行的调用入口。详见 [通用资源协议](CONTRACT.md)。

验证包含原有权限与编排用例，以及跨业务调用、输入/输出校验、停用、版本冲突、错误遮蔽、超时不重放、取消、旧数据迁移。截图及运行证据保存到本实验归档的 generic-resource-operations 目录。

本次检查：类型检查与构建通过，Core 测试 188/188，预览测试 15/15（381 次断言）。浏览器验证表单调用、JSON 参数校验、两类适配器共用入口及手机布局。
