# 插件配置样例

三个 `_conf_schema.json` 使用 AstrBot 的声明习惯，供插件中心交互原型读取：

- `voice`：资源绑定、音色偏好、概率与长度、实例/群覆盖。
- `recall`：条件显示、自动撤回和手动操作配置。
- `image-studio`：MCP 引用、后台交付偏好和多种绘图预设模板。

这是配置与页面设计样例，尚未附带可安装的业务实现或接通正式配置 API。`scope` 是本项目提出的扩展，运行时支持状态见 [插件中心设计](../plugin-center.md)。

运行 `bun run preview:plugins` 可查看自动生成的表单，默认端口 19336。样例操作仅在浏览器保存。
