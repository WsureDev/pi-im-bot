# 设置页视觉与交互优化

## 问题与源码对照

原移植保留了组件，但缺少 AstrBot 的配置工作区布局和样式配套。页面背景、卡片和输入区接近同一颜色，卡片动作中的主按钮又继承为文字按钮；常用编辑区被通用折叠面板隐藏。JSON 预览和打开按钮还放在横向 flex 容器中，打开后的 Monaco 实测只有约 98px 高、456px 宽。

本次对照固定版本 AstrBot v4.28.0：

- `components/config/AstrBotCoreConfigWrapper.vue` 用分类导航、清晰分组、行间距和柔和分隔组织配置。
- `views/ConfigPage.vue` 将范围选择与保存操作留在易找到的位置，用明确的主题色强调主操作。
- `components/shared/PersonaForm.vue` 直接展示主要字段，将折叠用于次要内容。
- `scss/_variables.scss` 和 `scss/components/_VCard.scss` 定义统一的颜色、圆角、间距和卡片边界。

采用这些组织方式，并按本次反馈让配置分组保持展开。基础控件仍来自 Vuetify，Schema 仍由现有 AstrBot 组件渲染。

## 改动

1. 设置页按人格与回复、消息与媒体、运行与队列、资源、权限、输出分组，使用定位导航和常驻保存栏。全部可编辑字段直接展示。
2. JSON 编辑区使用完整行宽和明确的 280px 视口，工具栏独立布局；进入视区后加载，取消导致占位与编辑区短暂叠放的切换动画。全屏编辑保持 viewport 尺寸，返回时维持内联尺寸。
3. 人格、Provider 请求参数和模型、OneBot 目标、插件安装与目录源、流程处理器直接展开；已有模板条目默认展开。原始协议、历史记录等诊断内容仍可按需展开。
4. 明亮主题采用冷灰画布、白色卡片、浅色输入背景、蓝色主操作和柔和边界；深色主题使用对应的深蓝灰层次。修正主题变量的颜色写法，Monaco 跟随当前主题。
5. Bot 设置与人格草稿独立复制和保存。一次保存只推进自身对应的版本和基线，保留另一组未保存的内容，避免互相夹带或重载覆盖。

## 验证

共享浏览器验证桌面 1440px、平板 900px 与手机 390px。桌面编辑器约 829×280px，手机约 263×280px；全屏约 1440×936px。加载、全屏回切、主题切换和窗口变化均核对编辑器与父容器边界，页面没有横向溢出。

核对了主按钮与背景颜色、主要字段无需展开即可编辑、代码内容保存、配置事件保留草稿、设置/人格交错保存和版本更新。测试使用独立配置及禁用外部执行的本地 Bot，结果与截图归入原研究实验的后续记录。

本轮改动作用于 Dashboard；正式 19335 的发布仍以之后确认的构建为准。
