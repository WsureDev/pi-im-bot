# 密钥输入改为 AstrBot 标准显隐方式

移除密码字段上方的“保留 / 替换 / 清除”和状态行，复用 AstrBot 的 Vuetify 密码框及 `mdi-eye-outline` / `mdi-eye-off-outline` 显隐方式。密钥列表继续使用已有的 AstrBot `ListConfigItem`。

覆盖插件动态配置、资源提供者/实例配置、模型 Provider API Key、OneBot Access Token 和旧 GSVI 配置输入。已保存值在打开编辑表单时读入，默认掩码，眼睛切换原值可见性。编辑内容即替换，清空后保存即清除；未修改的字段保持原值。旧的清除复选框也已移除。

配置保存仍使用原有版本检查和秘密字段更新协议，动作由表单自动生成，不再要求用户选择动作。常规状态、配置 GET 和列表继续只提供秘密字段的 configured 状态或掩码；编辑表单使用针对该对象的 POST 私密读取，检查 revision/release/target 并设置 no-store。原值不会写入前端持久存储或日志。这个编辑接口遵循家庭 LAN 管理工作台的既有直接访问方式，没有增加登录门槛。

测试使用独立 19386 数据目录和 TEST_ONLY 占位凭据，未替换 19385 或正式 Bot 的任何密钥。覆盖掩码/显示/隐藏、查看不产生修改、原值保留、替换重开、清空，以及普通状态不返回秘密原值。嵌套对象、秘密列表和模板稳定 ID 的读取与保存另有单元验证。
